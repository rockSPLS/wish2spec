# Wish2Spec

Ассистент заявок пользователей: помогает аналитику разобрать пожелания по документам команды — говорит, есть ли такое уже в системе или в прежних заявках, и для нового готовит основу ТЗ. У каждого вывода — ссылка на фрагмент документа, из которого он сделан.

> Проект в разработке: сейчас готов каркас, продукт появится в версии 0.1. Ход работы — в [DEV_NOTES.md](DEV_NOTES.md).

## Что это и зачем

**Проблема.** Пожелания пользователей приходят пачками и сформулированы по-разному: «хочу, чтобы напоминало об оплате», «присылайте письмо, если абонемент кончается». Аналитик для каждого вспоминает или ищет: может, это уже есть; может, такую заявку уже заводили; к какому модулю это относится. Только потом пишет ТЗ — и снова ищет, что уточнить у автора.

**Для кого.** Аналитик или владелец продукта, у которого есть документы о своей системе: справка, прежние ТЗ, список заявок, глоссарий.

**Почему AI и почему не обычный чат.** Языковая модель хорошо переформулирует и раскладывает текст по шаблону, но не знает вашу систему и придумает несуществующие модули. Wish2Spec сначала находит в ваших документах фрагменты, близкие по смыслу к пожеланию (поиск по эмбеддингам, RAG), и даёт модели только их. Вердикт — «уже есть», «похоже на заявку №…», «новое», «не про систему», «неясно» — всегда с источниками, которые можно открыть и проверить. Поэтому Wish2Spec работает только вместе с документами команды: без них ему не на что опереться.

## Технологии и почему

Подробно, с отвергнутыми вариантами, — в [журнале решений](docs/decisions-log.md).

- **Next.js (App Router) + TypeScript + Tailwind CSS** — интерфейс и серверная часть в одном проекте. Сервер нужен: ключ языковой модели нельзя держать в браузере.
- **AI SDK v6 + `@ai-sdk/openai-compatible`** — подходит любой OpenAI-совместимый сервис (Vercel AI Gateway, OpenRouter, OpenAI): достаточно вписать свой адрес, ключ и модель. Версия 6 работает и на Node 20, 7-я требует Node 22.
- **Локальные эмбеддинги — `@huggingface/transformers`** с моделью `Xenova/multilingual-e5-small` (многоязычная, понимает русский, лицензия MIT). Бесплатно и без лимитов, документы при индексации не покидают компьютер, кроме `npm install` ничего ставить не нужно. Есть запасной режим — эмбеддинги через тот же сервис по ключу.
- **zod** — проверка настроек и входных данных на сервере.
- **Хранение — JSON-файлы в папке `data/`** (не попадает в репозиторий). Деплоя нет, приложение работает локально.

## Как устроено

Будет заполнено в версии 0.1. Коротко: документы → фрагменты → эмбеддинги → поиск близких фрагментов к каждому пожеланию → вердикт модели с источниками → основа ТЗ для нового.

**Что куда отправляется.** Документы разбиваются на фрагменты и превращаются в эмбеддинги на вашем компьютере (в режиме `EMBEDDINGS_MODE=local`). В сервис языковой модели уходят только текст пожелания и найденные к нему фрагменты. В режиме `EMBEDDINGS_MODE=api` в сервис уходят и все фрагменты документов — для расчёта эмбеддингов.

## Запуск

Нужен **Node.js 20.9 или новее** (проверено на 20.11.1) и ключ OpenAI-совместимого сервиса языковой модели.

1. Установить зависимости:
   ```bash
   npm install
   ```
2. Скопировать `.env.example` в `.env.local` и заполнить значения — что означает каждая переменная, написано в самом файле. Все обязательны, кроме `LLM_REASONING_EFFORT` и `EMBEDDINGS_API_MODEL` (нужна только при `EMBEDDINGS_MODE=api`). Если чего-то не хватает или значение в неверном формате, маршрут проверки подключений (ниже) назовёт эти переменные; если сервис отклонит ключ или модель — покажет его ответ.
3. Запустить:
   ```bash
   npm run dev
   ```
   и открыть http://localhost:3003. Приложение открывается только на компьютере, где оно запущено, — другие устройства в сети его не видят. Если порт 3003 занят, можно выбрать другой:
   ```bash
   npm run dev -- -p 4000
   ```

При первом расчёте эмбеддингов (первая проверка подключений, а потом — первая индексация документов) локальная модель скачивается с Hugging Face (около 135 МБ, один раз) в папку `data/models/`.

**Маршрут проверки подключений.** При запущенном `npm run dev` скопируйте в адресную строку браузера адрес http://localhost:3003/api/dev/check: модель ответит на короткий вопрос по-русски, а для трёх фраз посчитаются эмбеддинги. В production-сборке этот адрес отвечает 404. Отдельно проверить только локальные эмбеддинги, без ключа:

```bash
npm run check:embeddings
```
